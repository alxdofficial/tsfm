- **Code says:** datascripts/harth/convert.py ACTIVITIES_BY_INT maps integer codes 1->walking,2->running,3->shuffling,4->stairs_up,5->stairs_down,6->standing,7->sitting,8->lying, then 9->cycling_sit, 10->cycling_stand, 11->transport_sit, 12->transport_stand (lines 50-61). parse_label() returns None for any integer not in {1..12}, and those rows are silently skipped during conversion.

- **Location:** `datascripts/harth/convert.py:58-61 (evidence: benchmark_data/processed/tsfm_eval/harth/label_native.npy has no cycling/transport windows; data/harth/labels.json has 8 activities)`
- **Fix:** Map the real HARTH integer codes (13->cycling_sit, 14->cycling_stand, and 130/140 to the paper's transport(sit)/transport(stand) equivalents or explicit cycling-inactive labels) and re-run conversion so cycling/transport windows are retained; verify all 12 classes appear before treating HARTH as a 12-class eval set.

### [CRITICAL] `pamap2` — channels ✅verified
- **Code says:** datascripts/pamap2/convert.py:47-56 builds COLUMN_NAMES by first listing all 39 non-orientation channels (hand/chest/ankle temp,acc16,acc6,gyro,mag) and then APPENDING all 12 orientation columns at the very end. pandas read_csv assigns these names positionally, so every raw column from index 16 onward is mislabeled. - **Paper says:** Thesis Appendix B, Table B.2 (PDF page 162, labeled p.153) gives the published PAMAP2 format: 54 columns = timestamp(1), activityID(2), heart rate(3), IMU hand(4-20), IMU chest(21-37), IMU ankle(38-54). PAMAP2 is a TRAINING dataset and datasets/imu_pretraining_dataset/multi_dataset_loader.py:377-414 loads every acc/gyro/mag/ori channel and pairs each with its manifest description, so HALO is trained on corrupted chest/ankle channels bound to incorrect channel text. (The zero-shot eval path uses only core_channels hand_acc16 + hand_gyro, which happen to be correctly aligned, so eval of other datasets is unaffected.)
- **Location:** `datascripts/pamap2/convert.py:47-56 (COLUMN_NAMES); data/pamap2/manifest.json chest_*/ankle_*/*_ori channels; verified in data/pamap2/sessions/*/data.parquet`
- **Fix:** Rebuild COLUMN_NAMES in the true raw order (orientation as columns 14-17 within each IMU block, per Table B.2) and re-run the conversion, or drop orientation entirely while preserving the correct per-IMU interleave. Verify post-fix that chest_temp is ~30-35 C and chest_acc magnitudes are ~9.8 m/s^2 at rest.
